## Synopsis

```bash
apo automations list [--project <id>] [--json]
```

## Options

| Option | Default | Description |
|---|---|---|
| `--project <id>` | saved project | Project whose automations to list. |
| `--json` | off | Emit the raw API response instead of a table. |

## Notes

- Requires backend auth (run [`apo login`](/cli/auth/) first, or pass `--api-key`).
- A `disabled` state with a failing last delivery means the automation hit ten consecutive delivery failures and switched itself off. Re-enable it from the dashboard after fixing the endpoint — re-enabling resets the counter.
- Creating automations is [`apo automations create`](/cli/automations-create/); deleting and testing live in the dashboard (or `DELETE`/`POST /test` on `/v1/automations/{id}`).
